이 방침은 박강민이 운영하는 Gangmin Personal Assistant의 Google 계정 연동과 관련 데이터 처리에 적용됩니다.

접근하는 정보와 목적

사용자가 Google OAuth에서 승인한 범위에 따라 계정 식별 정보, Gmail 메시지·첨부파일, 캘린더 일정 정보와 Tasks 할 일 정보에 접근할 수 있습니다. 정보는 사용자가 요청한 메일 확인·요약·초안 작성, 일정·할 일 관리, 업무 알림을 수행하는 데 사용합니다. 계정 비밀번호는 수집하지 않습니다.

외부 서비스 이용과 공유

요청을 처리하는 데 필요한 메일·일정·할 일 내용이나 요약은 설정된 AI 모델 제공자(예: OpenAI)에 전송되어 분석될 수 있습니다. 결과와 알림은 사용자가 선택한 메신저(예: Slack)에 전달될 수 있습니다. 해당 서비스의 저장과 처리는 각 서비스의 정책 및 운영자 계정 설정에도 영향을 받습니다. 외부 처리가 필요한 경우에도 요청 수행에 필요한 범위로 전송을 제한해야 합니다.

운영자는 Google 사용자 데이터를 판매하거나 광고 목적으로 이용하지 않으며, 범용 AI·머신러닝 모델 학습 목적으로 제공하지 않습니다. Google API로부터 받은 정보의 사용 및 다른 앱으로의 전송에는 Google API Services User Data Policy와 해당 정책의 Limited Use 요구사항을 적용합니다.

저장과 보호

OAuth 인증정보와 자동화 작업 기록·결과는 운영자가 관리하는 컴퓨터 및 연결된 서비스에 저장될 수 있습니다. 작업 기록에는 원문 일부 또는 요약이 포함될 수 있습니다. OAuth 토큰, API 키, 실제 메일·일정·할 일 데이터는 이 공개 웹페이지나 공개 소스 저장소에 게시하지 않습니다. 공개 안내 페이지는 GitHub Pages에서 호스팅합니다. 공개 호스팅은 Google 업무 데이터의 저장 용도로 사용하지 않습니다.

연결 해제와 데이터 삭제

Google 계정의 서드 파티 연결 관리에서 이 앱의 접근 권한을 철회할 수 있습니다. 권한 철회는 이미 저장된 로컬 기록이나 외부 서비스의 메시지·기록을 자동으로 삭제하지 않습니다. 보관된 기록과 인증정보의 삭제는 운영자가 해당 저장 위치 및 서비스에서 별도로 처리해야 합니다.
